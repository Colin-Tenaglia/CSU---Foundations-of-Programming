Drake Practice Returns

Six fact patterns to key into Drake, staged to the gates. Each names what it is testing, plants specific errors, and ends with a check sheet.

Every name, address, employer and SSN is invented. The SSNs sit in the 400-00 range, which is never issued. Use Drake practice returns only — never live client data.

How the check sheet works. Rows marked arithmetic can be verified the moment the income is entered. Rows marked capture are filled in from Drake on the first clean run and become the key for every run after, so the key is the software’s own arithmetic rather than a number typed from memory. Rows marked the student decides have no single right entry — they are the judgment the scenario exists to test.

Work them in order. PR-1 is the floor and exists to prove data entry discipline. PR-2 is the Gate 1 specification exactly — unassisted, under 45 minutes, zero critical errors.

Companion to the EA Track workbook. Screen codes verified against Drake KB 20051; confirm against your installed year.
